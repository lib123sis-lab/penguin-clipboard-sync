# 小企鹅剪贴板同步 · Windows 客户端

小企鹅输入法（fcitx5-android 私有分支）的 Windows 端剪贴板同步客户端构建产物仓库，仅用于公开下载，不含源码。

## 下载

- 最新：[v0.6.0.1026](https://github.com/lib123sis-lab/penguin-clipboard-sync/releases/tag/v0.6.0.1026)
- 文件：`PenguinClipboardSync-v0.6.0.1026-win-x64.exe`（Windows 10/11 x64，单文件，双击运行）
- SHA-256：`2eec9c9c6276549983fc6186367cb771ac458c725a5b7f0ad6210f5895413153`

## 使用

1. 手机端小企鹅输入法进入「剪贴板 → 多端剪贴板同步」，开启并生成邀请码。
2. 在 Windows 客户端填入邀请码与手机显示的局域网地址完成配对。
3. 两端需在同一局域网；Windows 防火墙需放行客户端。
